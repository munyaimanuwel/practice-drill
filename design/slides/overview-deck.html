Interview Drill

A personal interview practice app — scheduled quizzes and code challenges, answered in the browser or your IDE, then graded.

The problem

Interview readiness decays without repetition. Random tutorials aren't drills — no schedule, no submission, no feedback loop.

⏰

Ad hoc study

Practice happens only when motivation strikes, not on a plan.

🧩

No real format

Reading ≠ answering questions under time pressure.

📭

No feedback

Solved challenges sit unreviewed in folders.

What it is

Single-user web app that schedules drill sessions and closes the loop: answer → submit → request grade.

📝

Quiz sessions

Timed question sets answered directly in the browser, saved as drafts until final submit.

💻

Code challenges

Download a starter pack, solve in Cursor/VS locally, upload your solution zip.

🎯

Graded review

Mark any session "request grade" and get score plus written feedback.

Two flows, one loop

QuizIn the browser

  • Pick session from dashboard
  • Answer each question
  • Save draft anytime
  • Submit & request grade

CodeIn your IDE

  • Download starter zip
  • Open in Cursor / VS
  • Solve locally
  • Upload solution zip → grade

Momentum, measured

Sessions completed per week since launch of the drill habit.

Boring stack, on purpose

Optimized for maintainability by one person. No sandboxed execution of uploads — grading is manual or agent-assisted later.
